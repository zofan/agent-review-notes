# Agent Review Notes

Экспериментальный плагин GoLand для локальных замечаний к коду. Пользователь выделяет код или
ставит каретку, пишет только текст замечания, а плагин сохраняет путь, диапазон, Git snapshot и
контекст в открытом JSON-контракте для AI-агента.

## Возможности

Плагин поддерживает полный локальный цикл:

1. создать замечание из editor selection/caret;
2. сохранить его без изменения исходного файла;
3. показать замечание в gutter и tool window;
4. пережить внешнее изменение JSON и кода;
5. либо точно перепривязать замечание, либо пометить его как требующее ручной привязки.

## Локальные данные

Заметки проекта хранятся вне Git в:

```text
<project>/.idea/agent-review-notes/notes/<id>.json
```

Одна заметка соответствует одному JSON-файлу. Контракт имеет версию
`agent.review.note.v1`. Плагин не использует сеть и не запускает AI-агентов.

## Сборка

Gradle можно запустить на встроенном JBR GoLand. Java 21 нужна как compiler toolchain;
Foojay resolver загружает её автоматически, если локального JDK 21 ещё нет:

```bash
export JAVA_HOME="$HOME/.local/share/JetBrains/Toolbox/apps/goland/jbr"
./gradlew test buildPlugin verifyPlugin
```

ZIP плагина появляется в `build/distributions/`.

## Статус

Готовое локальное решение для GoLand. Перед публичным распространением рекомендуется ручная
проверка установки и основных сценариев в поддерживаемой версии IDE.

## Идеи для фич

- [x] Если в проекте есть Git, заметки привязываются к ветке
- Окошко для просмотра заметок
- Изменение удаление заметов через общее окно со списком заметок
- Фильтры по типу в списке заметок
- Заметку можно оставить в месте установленной каретки (файл и строка автоматически определяется)
- Заметку можно оставить к папке целиком, например на все содержимое или на папку как на путь если нейминг неверный или расположение
- Заметку можно оставить на выделение участка кода
- Заметки после их создания встраиваются в код и отображаются визуально с иконкой по типу
